## Контрольне запитання

**Питання:** Як перейменувати стовпець у DataFrame?


**Відповідь:** Стовпець перейменовують методом `rename()` з параметром `columns`, у який передають словник «старе ім'я: нове ім'я»:

```python
new_df = df.rename(columns={'quantity': 'qty'})
```

Особливості методу:
- за замовчуванням `rename()` не змінює початковий DataFrame, а повертає новий. Тому результат потрібно зберегти в змінну (`df = df.rename(...)`) або вказати `inplace=True`, тоді DataFrame змінюється на місці;
- за один виклик можна перейменувати кілька стовпців: `df.rename(columns={'quantity': 'qty', 'price': 'unit_price'})`;
- якщо вказати стовпець, якого немає в таблиці, він буде проігнорований без помилки. Щоб отримати помилку `KeyError`, потрібно додати параметр `errors='raise'`.

Другий спосіб: присвоїти список нових імен усіх стовпців атрибуту `columns`. Список має містити стільки імен, скільки в таблиці стовпців, і в тому ж порядку:

```python
df.columns = ['id', 'date', 'store', 'product', 'qty', 'price']
```

Для нашої таблиці після `df.rename(columns={'quantity': 'qty'})` стовпці матимуть імена `['order_id', 'date', 'store_id', 'product_id', 'qty', 'price']`.

## Висновки

Під час виконання лабораторної роботи я навчився працювати з бібліотекою pandas: завантажувати дані з CSV-файлу у DataFrame, робити первинний аналіз (`head`, `tail`, `info`, `describe`), фільтрувати рядки за умовами, сортувати дані, групувати їх і обчислювати агреговані значення (`groupby`, `nunique`), додавати нові стовпці, видаляти стовпці й рядки з пропущеними значеннями та будувати зведені таблиці (`pivot_table`).
